# Math Games

Interactive maths games for Grade 2 and Grade 3, made by Teacher Dima Abuhaifa.

## Adding a new game
1. Put the game's folder inside `grade-2/` or `grade-3/` (the folder holds an `index.html`).
2. Add one line for it in `assets/lessons.js`. The grade page lists it automatically.

The **Times Tables Trainer** (tables 1 to 10, for both grades) lives in `times-tables/`. Open it with `?g=2` or `?g=3` to pick the grade.
